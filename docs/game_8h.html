Device game states, including the temporary backend-wait state.

Enumerator

Wait for game initialization.

Run the LED phase and temperature puzzle.

SERIAL_PUZZLE 

Run the serial password puzzle.

BACKEND_PUZZLE 

Wait while the player solves the server puzzle.

Request the next state from the backend.
